# Rushank Lashkari, Sydney Harbour portfolio

A scroll-driven portfolio over a photorealistic 3D Sydney Harbour (Google Photorealistic 3D Tiles via Cesium ion, rendered with CesiumJS).

Static site: deploy the repo root on Netlify with no build command. The Cesium ion token is in `index.html`; restrict its Allowed URLs in Cesium ion to the live domain.
